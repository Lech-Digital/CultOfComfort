# Cult of Comfort 0.2.1 (version code 3)

The game tells you when there's a new version (as Coo does). Built from `7b653ca`; the server (`/api/app-version`:
latest 3, minimum 2) was deployed on 2026-11-21.

## What's new on Google Play (en-US)

```
The game now tells you when a new version is out, and can update itself without leaving it.
```

## Everything in this release
- On launch, and on coming back (at most once an hour), the game asks Google Play and the Cult's server about updates:
  - A normal release downloads in the background; "Restart to update" when it's in.
  - A release with priority 4 or 5 (set in the Play Console), or one the server requires, is Play's full-screen update.
  - When Play hasn't offered it yet but the server knows a newer version: "A new version is on Google Play", once a day.
  - A version too old for the server: update to keep playing.
- With each release, raise `AppUpdates__Latest` in `deploy/docker-compose.prod.yml` to the new version code and deploy;
  raise `AppUpdates__Minimum` when the server stops understanding an older client.
