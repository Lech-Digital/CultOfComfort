# HUD Kit & Game Frame — Design

- **Date:** 2026-10-11
- **Status:** Approved by the owner (2026-10-11)
- **Implements:** step 3 of `2026-10-10-art-direction-and-pipeline-design.md`, widened to a full game frame
- **Out of scope:** real economy data (Timber, Peat, Devotion, Pennies, Comfort, Tension), the screens behind locked buttons, lighting (step 5), sound

## Intent

Make the interface look like a finished F2P base-builder (the owner's bar: "at least as good as Kingshot") in the
chosen **Manuscript + Junk** voice, as **one solid pass**. The owner explicitly wants to avoid a "not good enough"
polish loop: ship this, then build buildings; deeper polish waits until the game is playable.

## Decisions

| Topic | Decision |
|---|---|
| Layout | **C · Junk drawer** structure: resource pills on top, hazard-tape Tension strip across, shortcut buttons at the sides, bottom bar with bright sticky-note actions |
| Surfaces | **B's parchment**: every panel is a neat illuminated-manuscript sheet (ink border, 9-slice); the 2024 junk (tape, sticky notes, hazard tape, marker scribbles) is slapped on top |
| Frame scope | Full game frame (resources, portrait, Tension, shortcuts) even though most features do not exist yet |
| Unbuilt features | Shown **locked**: greyed + padlock; a tap slaps a marker-written sticky note with the unlock condition and a joke |
| Placeholder data | One client-side source of **demo values**; each demo value carries a visible "demo" mark |
| Kit textures | Generated by a **Python (Pillow) script**, deterministic (seeded) — replaces the art spec's "author as SVG" (no new toolchain, same reproducibility) |
| Icons | **Rendered from Blender models** through the existing pipeline (transparent background), so icons match the 3D art |
| Fonts | IM Fell English, IM Fell English SC (manuscript voice), Permanent Marker (the Prophet's voice); OFL, bundled with licence files |
| Tech | Unchanged: UI Toolkit built in code (`HudView`) + `Hud.uss`; simulation untouched (determinism hash stays `12c3fe1f0e23fb59`) |

## The kit

Written by `art/ui/make_kit.py` to `Assets/Resources/UI/Kit/` (bilinear filtering, no mips, uncompressed):

| Texture | Use |
|---|---|
| `parchment` | 9-slice panel: warm paper with fibres, darker edges, thin red-brown ink rule inset from the border |
| `parchment_dark` | Darker 9-slice for the bottom bar and pill backgrounds |
| `note_yellow`, `note_pink`, `note_green`, `note_blue` | Sticky notes (square, slight curl shadow at the bottom edge) |
| `tape_a`, `tape_b` | Translucent masking-tape strips with torn ends |
| `hazard` | Tileable yellow/black diagonal stripes for meters |
| `scribble_underline`, `scribble_circle` | Marker strokes (white, tinted in USS) |
| `padlock` | Locked badge |
| `stamp_verified`, `stamp_mismatch` | Rubber-stamp verdicts for the Dawn card |

## Icons

Built by `./art/build.sh --icons` from modules in `art/blender/icons/` to `Assets/Resources/UI/Icons/` (128 px, transparent):

- **Resources:** `timber` (log), `scrap` (horseshoe), `peat` (peat brick), `devotion` (candle), `penny` (silver coin), `comfort` (rubber duck, reusing the model)
- **Skills:** `sluice` (sluice gate), `voice` (tin-can phone), `stones` (reusing `fx_hot_stone`), `speed` (snail)
- **Shortcuts:** `map` (rolled map), `research` (reusing `fx_hymnal`), `missionaries` (sandal + staff), `tithes` (coin pouch), `shop` (reusing `shopping_trolley`), `cult` (cultist head), `settings` (cog)
- **Portrait:** `portrait_prophet` (the Prophet's head and shoulders)

## Screens

**Frame (all phases):** a row of resource pills (Timber, Scrap, Peat, Devotion — each `value/cap`; Pennies as a sticky note
with a "+"); below it the Prophet portrait with a Hearth-level badge, a taped parchment label "Hearth Lv 1 · Comfort 42",
and a Settings button on the right.

**Dusk:** the hazard-tape **Tension strip** slices across under the frame with a marker note ("Wulfric's coming in ~3h");
shortcut buttons Map + Research on the left, Missionaries + Tithes on the right; tower choices as sticky notes; bottom
bar = Shop · **Light the Lamps** (big) · Cult.

**Night:** the Tension strip becomes a **wave strip** ("Wave 3/4 · 11 on the road"); Hearth and Prophet health are
hazard-tape meters; shortcuts hide; skills are sticky-note buttons with icons, cooldown text and a disabled look; the
speed button is a snail with "1× / 2× / 4×".

**Dawn:** the result card is a parchment page: a title in IM Fell SC, the summary and flavour text, small-print hashes,
and a rubber stamp (VERIFIED / MISMATCH).

**Announcements:** the world's voice on a parchment ribbon; the Prophet's quips on a sticky note in Permanent Marker.

**Settings (real, small):** a parchment sheet with Recenter camera, the determinism line (development builds), the build
version, and a "Sound: there is no sound yet" line. The old free-floating Recenter chip moves here.

**Portrait and landscape** both use the same pieces; landscape puts the shortcut columns beside the board and the bottom
bar's tower notes inline with the main button.

## Locked features

| Button | Note (Permanent Marker) |
|---|---|
| Map | "World map: the Prophet is still arguing with the cartographer. Coming soon." |
| Research | "Research table unlocks at Hearth 3. He's still reading the manual." |
| Missionaries | "Missionaries: nobody has volunteered yet. Coming soon." |

| Shop | "Shop: the till is a bucket. Coming soon." |
| Cult | "Your cult: five people and a duck. Coming with buildings." |

Tapping a locked button shows its note (taped, slightly rotated) for 3 s or until the next tap. Each entry flips to a
real screen when its feature lands; the table lives in one place in code.

## Placeholder data

A `DemoEconomy` class supplies Timber 480/1000, Peat 120/1000, Devotion 15/1000, Pennies 50, Comfort 42, Tension 62 %
("~3h"), Hearth level 1. Scrap and everything in the Night are real. Demo pills show a small "demo" mark; the buildings
work replaces `DemoEconomy` with real base state and removes the marks.

## Verification

- **Automated (PlayMode):** the frame is present in Dusk, Night and Dawn; tapping a locked button shows its note;
  Dusk → Night swaps the Tension strip for the wave strip and the build notes for the skill notes; portrait ↔ landscape
  restacks; demo pills carry the demo mark and Scrap does not.
- **Automated (EditMode):** every kit texture, icon and font loads from Resources.
- **Automated (Python):** the kit generator is deterministic (same bytes twice) and writes every texture listed above.
- **Automated (Blender):** every icon module builds within budget and renders a 128 px PNG with a transparent background.
- **Existing suites stay green:** 56 .NET, Blender, EditMode, PlayMode; determinism hash unchanged.
- **Device:** Pixel 10 screenshots in portrait and landscape for Dusk, Night, Dawn and a locked note; 60 fps held in Dusk and
  in a busy Night.
