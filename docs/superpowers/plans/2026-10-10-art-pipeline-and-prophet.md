# Art Pipeline + The Prophet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Blender-scripted asset pipeline (spec step 0) and use it to produce the Prophet and put him in the game, animated in code (spec step 1a).

**Architecture:** Python scripts under `art/blender/` run in headless Blender 4.5 LTS: they build low-poly meshes coloured by sampling one shared palette texture, verify budgets, export FBX into `Assets/Resources/Art/Models/`, and render day/night previews into `art/previews/`. In Unity, `ArtLibrary` loads models by name (falling back to today's primitives when missing) and `PartAnimator` animates named rigid parts from state `BattleView` already tracks.

**Tech Stack:** Blender 4.5.14 LTS (bpy, bmesh, unittest), FBX, Unity 6000.3.26f1 + URP 17.3, NUnit (Unity Test Framework), adb.

**Spec:** `docs/superpowers/specs/2026-10-10-art-direction-and-pipeline-design.md`

## Global Constraints

- Blender **4.5 LTS** installed user-locally at `~/Applications/Blender.app` (no sudo); scripts find it via `$BLENDER` or that default path.
- Palette = exactly the spec's swatches; every face samples a swatch centre in one shared texture; one URP material (`Palette`) with GPU instancing.
- Budgets: **≤ 1,500 triangles per character**, ≤ 3,000 per building, ≤ 300 per prop/effect.
- Scale: **1 tile = 1 m**; the Prophet ≈ **1.0 m** tall; models face **+Z in Unity**, up **+Y**.
- Shape rules: chunky, small bevels, flat-shaded; 2024 items crisp; deadpan faces; Prophet silhouette = tallest + umbrella.
- Simulation untouched: all 56 .NET tests pass and the determinism probe hash stays **`12c3fe1f0e23fb59`**.
- Performance on the Pixel 10 development build: **60 fps in Dusk, ≥ 50 fps in a busy Night**.
- Git: commit and push only as **adziusmaster / `adzius.lech@gmail.com`** (repo-local config + hooks already enforce it); **never** add a `Co-Authored-By` or "Generated with" line.
- Paths used throughout: Unity = `$HOME/Unity/Hub/Editor/6000.3.26f1/Unity.app/Contents/MacOS/Unity`, adb = `~/android-sdk/platform-tools/adb`, project = `client/CultOfComfort.Unity`.

## Review Focus

1. **Blender missing or at another path** → `art/build.sh` must stop with a clear message naming the path and the `BLENDER` override, exit code 2 (Task 1, Step 4 checks it).
2. **A model not exported yet / deleted** → `ArtLibrary.Instantiate` returns `null` and the game falls back to primitives instead of crashing (Task 6 test `Instantiate_UnknownName_ReturnsNull`; Task 8 keeps the fallback path).
3. **FBX axis or scale wrong** (model lying down, facing backwards, 100× size) → Prophet is ~1 m tall, upright, `Front` marker at +Z (Task 8 tests `Instantiate_Prophet_IsAboutOneMetreTallAndUpright`, `Instantiate_Prophet_FacesPlusZ`).
4. **Palette texture blurred or compressed** so colours bleed between swatches → importer forces point filtering, no mipmaps, uncompressed (Task 6 test `PaletteTexture_ImportSettings_KeepSwatchesCrisp`).
5. **Wrong pivots** (swoon rotates around the belly, arms swing from the elbow) → Body pivot at the feet, arms at shoulder height (Task 8 test `Instantiate_Prophet_PivotsAtFeetAndShoulders`).

```python
"""Muddy Satire palette (spec: Style guide). Every model samples these swatch centres from one texture.

Pure Python on purpose: no bpy, so it is trivially testable and the PNG is byte-for-byte reproducible.
"""
import os
import struct
import zlib

COLUMNS = 8
CELL = 16  # pixels per swatch cell

SWATCHES = [
    # Ground & nature
    ("grass", "#6f7a49"), ("grass_alt", "#687244"), ("road_mud", "#8a6a47"), ("wet_mud", "#4e3520"),
    ("water", "#5b7f86"), ("foliage", "#6f8a3a"), ("pine", "#4c5b33"),
    # Building materials
    ("roman_marble", "#d7cfbf"), ("worn_stone", "#b8b0a2"), ("fieldstone", "#7f7b73"), ("fresh_log", "#9b7a52"),
    ("old_wood", "#6d4c2f"), ("tarred_wood", "#4a321e"), ("thatch", "#a08450"), ("daub", "#bfa98a"),
    # People
    ("prophet_skin", "#e7b590"), ("local_skin", "#d9a37f"), ("linen", "#ece6d6"), ("levy_wool", "#9c8460"),
    ("mail", "#8e9399"), ("zealot_red", "#a8432c"), ("wulfric_red", "#8a2f24"), ("gold_trim", "#d9b45a"),
    # 2024 junk
    ("cone_orange", "#ff5a00"), ("tarp_blue", "#1f6dff"), ("hivis_yellow", "#e8ff3a"), ("flipflop_pink", "#ff4fa3"),
    ("umbrella_black", "#2b2b2e"),
    # Emissive
    ("fire", "#ffb04d"), ("ember", "#ff7a1f"), ("window", "#ffcf80"), ("moon_rim", "#9fe3ea"),
]

_INDEX = {name: i for i, (name, _) in enumerate(SWATCHES)}
ROWS = -(-len(SWATCHES) // COLUMNS)

_REPO = os.path.abspath(os.path.join(os.path.dirname(__file__), "..", ".."))
UNITY_ART_DIR = os.path.join(_REPO, "client", "CultOfComfort.Unity", "Assets", "Resources", "Art")
UNITY_PALETTE_PATH = os.path.join(UNITY_ART_DIR, "Palette.png")


def rgb(name):
    h = dict(SWATCHES)[name].lstrip("#")
    return tuple(int(h[i:i + 2], 16) for i in (0, 2, 4))


def uv(name):
    """UV of the swatch's cell centre. Row 0 is the top of the image (v = 1 is the top in Blender and Unity)."""
    i = _INDEX[name]
    col, row = i % COLUMNS, i // COLUMNS
    return (col + 0.5) / COLUMNS, 1 - (row + 0.5) / ROWS


def swatch_at(u, v, tolerance=1e-4):
    for name in _INDEX:
        su, sv = uv(name)
        if abs(su - u) <= tolerance and abs(sv - v) <= tolerance:
            return name
    return None


def write_png(path):
    """8-bit RGB PNG, one CELL×CELL block per swatch, unused cells black."""
    width, height = COLUMNS * CELL, ROWS * CELL
    rows = []
    for y in range(height):
        row = bytearray([0])  # filter type: none
        for x in range(width):
            i = (y // CELL) * COLUMNS + x // CELL
            row += bytes(rgb(SWATCHES[i][0])) if i < len(SWATCHES) else b"\x00\x00\x00"
        rows.append(bytes(row))

    def chunk(kind, data):
        return struct.pack(">I", len(data)) + kind + data + struct.pack(">I", zlib.crc32(kind + data) & 0xFFFFFFFF)

    png = b"\x89PNG\r\n\x1a\n"
    png += chunk(b"IHDR", struct.pack(">IIBBBBB", width, height, 8, 2, 0, 0, 0))
    png += chunk(b"IDAT", zlib.compress(b"".join(rows), 9))
    png += chunk(b"IEND", b"")
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "wb") as f:
        f.write(png)
```

`art/blender/lib/mesh.py`:

```python
"""Low-poly building blocks. A Part is one mesh object (one animatable piece) made of several coloured pieces."""
import math

import bmesh
import bpy
from mathutils import Euler, Matrix, Vector

import palette

MATERIAL_NAME = "Palette"


def palette_material():
    material = bpy.data.materials.get(MATERIAL_NAME)
    if material is not None:
        return material
    material = bpy.data.materials.new(MATERIAL_NAME)
    material.use_nodes = True
    nodes = material.node_tree.nodes
    bsdf = nodes["Principled BSDF"]
    texture = nodes.new("ShaderNodeTexImage")
    texture.interpolation = "Closest"  # swatches must not blend into each other
    texture.image = bpy.data.images.load(palette.UNITY_PALETTE_PATH, check_existing=True)
    material.node_tree.links.new(texture.outputs["Color"], bsdf.inputs["Base Color"])
    bsdf.inputs["Roughness"].default_value = 0.85
    return material


def world_position(obj):
    """Sum of locations up the parent chain. Parts are never rotated at build time, so this is exact,
    and unlike matrix_world it does not depend on a depsgraph update."""
    total = Vector((0, 0, 0))
    while obj is not None:
        total += obj.location
        obj = obj.parent
    return total


def _link(obj, parent):
    bpy.context.scene.collection.objects.link(obj)
    if parent is not None:
        obj.parent = parent
    return obj


def root(name):
    obj = bpy.data.objects.new(name, None)
    obj.empty_display_type = "PLAIN_AXES"
    return _link(obj, None)


def marker(name, location, parent):
    """A named empty that is exported, e.g. `Front` so Unity tests can check which way the model faces."""
    obj = bpy.data.objects.new(name, None)
    obj.empty_display_type = "SPHERE"
    obj.empty_display_size = 0.03
    _link(obj, parent)
    obj.location = Vector(location) - world_position(parent)
    return obj


class Part:
    def __init__(self, name, pivot=(0, 0, 0), parent=None):
        self.name = name
        self.pivot = Vector(pivot)
        self.parent = parent
        self.bm = bmesh.new()
        self.uv_layer = self.bm.loops.layers.uv.verify()

    # ---- pieces -------------------------------------------------------------------------------------------

    def box(self, size, center, swatch, bevel=0.015, rotation=(0, 0, 0)):
        piece = bmesh.new()
        bmesh.ops.create_cube(piece, size=1.0)
        bmesh.ops.scale(piece, vec=Vector(size), verts=piece.verts)
        if bevel > 0:
            bmesh.ops.bevel(piece, geom=list(piece.verts) + list(piece.edges), offset=bevel, offset_type="OFFSET",
                            segments=1, profile=0.5, affect="EDGES", clamp_overlap=True)
        return self._add(piece, center, swatch, rotation)

    def cylinder(self, radius, depth, center, swatch, segments=8, radius_top=None, rotation=(0, 0, 0)):
        piece = bmesh.new()
        bmesh.ops.create_cone(piece, cap_ends=True, cap_tris=False, segments=segments, radius1=radius,
                              radius2=radius if radius_top is None else radius_top, depth=depth)
        return self._add(piece, center, swatch, rotation)

    def sphere(self, radius, center, swatch, segments=10, rings=7, scale=(1, 1, 1)):
        piece = bmesh.new()
        bmesh.ops.create_uvsphere(piece, u_segments=segments, v_segments=rings, radius=radius)
        bmesh.ops.scale(piece, vec=Vector(scale), verts=piece.verts)
        return self._add(piece, center, swatch, (0, 0, 0))

    # ---- assembly -----------------------------------------------------------------------------------------

    def _add(self, piece, center, swatch, rotation):
        u, v = palette.uv(swatch)  # KeyError for unknown swatches, before any geometry is merged
        rot = Euler(tuple(math.radians(a) for a in rotation), "XYZ").to_matrix().to_4x4()
        bmesh.ops.transform(piece, matrix=Matrix.Translation(Vector(center) - self.pivot) @ rot, verts=piece.verts)
        layer = piece.loops.layers.uv.verify()
        for face in piece.faces:
            face.smooth = False
            for loop in face.loops:
                loop[layer].uv = (u, v)
        mesh = bpy.data.meshes.new("_piece")
        piece.to_mesh(mesh)
        piece.free()
        self.bm.from_mesh(mesh)  # appends to the part's geometry
        bpy.data.meshes.remove(mesh)
        return self

    def build(self):
        mesh = bpy.data.meshes.new(self.name)
        self.bm.to_mesh(mesh)
        self.bm.free()
        for polygon in mesh.polygons:
            polygon.use_smooth = False
        mesh.materials.append(palette_material())
        obj = _link(bpy.data.objects.new(self.name, mesh), self.parent)
        # Pivots are given in model space; a child stores its location relative to its parent.
        obj.location = self.pivot - world_position(self.parent) if self.parent is not None else self.pivot
        return obj
```

```python
"""Build-time guards from the spec: triangle budgets, palette-only colours, required named parts."""
import palette


class AssetCheckError(Exception):
    pass


def _meshes(root):
    return [o for o in [root, *root.children_recursive] if o.type == "MESH"]


def triangles(root):
    return sum(len(p.vertices) - 2 for o in _meshes(root) for p in o.data.polygons)


def off_palette(root):
    bad = []
    for obj in _meshes(root):
        layer = obj.data.uv_layers.active
        if layer is None or any(palette.swatch_at(d.uv[0], d.uv[1]) is None for d in layer.data):
            bad.append(obj.name)
    return bad


def missing_parts(root, required):
    names = {o.name for o in [root, *root.children_recursive]}
    return [name for name in required if name not in names]


def verify(root, budget, required):
    problems = []
    count = triangles(root)
    if count > budget:
        problems.append(f"{count} triangles > budget {budget}")
    off = off_palette(root)
    if off:
        problems.append(f"colours outside the palette on: {', '.join(off)}")
    missing = missing_parts(root, required)
    if missing:
        problems.append(f"missing parts: {', '.join(missing)}")
    if problems:
        raise AssetCheckError(f"{root.name}: " + "; ".join(problems))
```

```python
"""Golden Mud preview renders (spec: Lighting) at the game camera's elevation, three-quarter view."""
import math

import bpy
from mathutils import Vector

from lib.mesh import Part

GAME_ELEVATION = math.degrees(math.atan2(16.5, 10.4))  # matches CameraRig's offset (0, 16.5, -10.4)


def _engine():
    items = bpy.types.RenderSettings.bl_rna.properties["engine"].enum_items.keys()
    return "BLENDER_EEVEE_NEXT" if "BLENDER_EEVEE_NEXT" in items else "BLENDER_EEVEE"


def _bounds(root):
    points = [o.matrix_world @ Vector(c) for o in [root, *root.children_recursive] if o.type == "MESH" for c in o.bound_box]
    lo = Vector((min(p.x for p in points), min(p.y for p in points), min(p.z for p in points)))
    hi = Vector((max(p.x for p in points), max(p.y for p in points), max(p.z for p in points)))
    return lo, hi


def _light(name, kind, energy, color, rotation=(0, 0, 0), location=(0, 0, 0)):
    data = bpy.data.lights.new(name, kind)
    data.energy = energy
    data.color = color
    obj = bpy.data.objects.new(name, data)
    obj.rotation_euler = tuple(math.radians(a) for a in rotation)
    obj.location = location
    bpy.context.scene.collection.objects.link(obj)
    return obj


def _world(color, strength):
    world = bpy.data.worlds.new("Preview") if bpy.context.scene.world is None else bpy.context.scene.world
    world.use_nodes = True
    background = world.node_tree.nodes["Background"]
    background.inputs["Color"].default_value = (*color, 1)
    background.inputs["Strength"].default_value = strength
    bpy.context.scene.world = world


def render(root, day_path, night_path, size=512):
    bpy.context.view_layer.update()  # matrix_world is stale until the depsgraph runs
    scene = bpy.context.scene
    scene.render.engine = _engine()
    scene.render.resolution_x = scene.render.resolution_y = size
    scene.render.image_settings.file_format = "PNG"
    scene.view_settings.view_transform = "Standard"  # keep palette colours true

    lo, hi = _bounds(root)
    centre = (lo + hi) / 2
    extent = max(hi.x - lo.x, hi.y - lo.y, hi.z - lo.z)
    ground = Part("PreviewGround").box((extent * 4, extent * 4, 0.02), (centre.x, centre.y, lo.z - 0.01), "grass", bevel=0).build()

    camera_data = bpy.data.cameras.new("PreviewCamera")
    camera_data.type = "ORTHO"
    camera_data.ortho_scale = extent * 1.6
    camera = bpy.data.objects.new("PreviewCamera", camera_data)
    scene.collection.objects.link(camera)
    yaw, pitch = math.radians(30), math.radians(GAME_ELEVATION)
    direction = Vector((math.sin(yaw) * math.cos(pitch), -math.cos(yaw) * math.cos(pitch), math.sin(pitch)))
    camera.location = centre + direction * extent * 6
    camera.rotation_euler = (-direction).to_track_quat("-Z", "Y").to_euler()
    scene.camera = camera

    # Day: low warm sun from the left, cool sky fill.
    _world((0.55, 0.62, 0.72), 0.6)
    sun = _light("Sun", "SUN", 3.2, (1.0, 0.86, 0.66), rotation=(62, 0, -60))
    sun.data.angle = math.radians(3)
    scene.render.filepath = day_path
    bpy.ops.render.render(write_still=True)

    # Night: teal moon, orange fire beside the model.
    bpy.data.objects.remove(sun, do_unlink=True)
    _world((0.02, 0.04, 0.07), 1.0)
    _light("Moon", "SUN", 0.7, (0.55, 0.85, 0.9), rotation=(50, 0, 140))
    _light("Fire", "POINT", 60.0 * extent, (1.0, 0.55, 0.22), location=(centre.x - extent, centre.y - extent * 0.6, lo.z + extent * 0.5))
    scene.render.filepath = night_path
    bpy.ops.render.render(write_still=True)

    bpy.data.objects.remove(ground, do_unlink=True)
```

```python
"""Blender-side build driver. Run through ./art/build.sh, which passes arguments after `--`."""
import argparse
import importlib
import os
import sys

HERE = os.path.dirname(os.path.abspath(__file__))
if HERE not in sys.path:
    sys.path.insert(0, HERE)

import palette  # noqa: E402
from lib import checks, export, scene  # noqa: E402
from lib import preview as previews  # noqa: E402

PREVIEW_DIR = os.path.abspath(os.path.join(HERE, "..", "previews"))
MODEL_DIR = os.path.join(palette.UNITY_ART_DIR, "Models")


def build_asset(name, preview=True):
    module = importlib.import_module(f"models.{name}")
    scene.reset()
    root = module.build()
    checks.verify(root, module.TRIANGLE_BUDGET, module.REQUIRED_PARTS)
    result = {"fbx": os.path.join(MODEL_DIR, f"{name}.fbx"), "triangles": checks.triangles(root)}
    export.export_fbx(root, result["fbx"])
    if preview:
        result["day"] = os.path.join(PREVIEW_DIR, f"{name}_day.png")
        result["night"] = os.path.join(PREVIEW_DIR, f"{name}_night.png")
        previews.render(root, result["day"], result["night"])
    print(f"[art] {name}: {result['triangles']} triangles → {result['fbx']}")
    return result


def _all_models():
    folder = os.path.join(HERE, "models")
    return sorted(f[:-3] for f in os.listdir(folder) if f.endswith(".py") and not f.startswith("_"))


def main(argv):
    parser = argparse.ArgumentParser(prog="art/build.sh")
    parser.add_argument("names", nargs="*")
    parser.add_argument("--all", action="store_true")
    parser.add_argument("--no-preview", action="store_true")
    args = parser.parse_args(argv)
    names = _all_models() if args.all else args.names
    if not names:
        parser.error("name an asset (see art/blender/models) or pass --all")
    for name in names:
        build_asset(name, preview=not args.no_preview)


if __name__ == "__main__":
    main(sys.argv[sys.argv.index("--") + 1:] if "--" in sys.argv else [])
```

```csharp
using UnityEditor;
using UnityEngine;

namespace CultOfComfort.Editor
{
    /// <summary>Creates assets the code-first client depends on. Idempotent; also runs before every build.</summary>
    public static class ProjectSetup
    {
        public const string BaseMaterialPath = "Assets/Resources/BaseLit.mat";
        public const string PaletteTexturePath = "Assets/Resources/Art/Palette.png";
        public const string PaletteMaterialPath = "Assets/Resources/Art/Materials/Palette.mat";

        [MenuItem("Cult of Comfort/Ensure Project Assets")]
        public static void EnsureAssets()
        {
            EnsureBaseMaterial();
            EnsurePaletteMaterial();
        }

        private static void EnsureBaseMaterial()
        {
            if (AssetDatabase.LoadAssetAtPath<Material>(BaseMaterialPath) != null)
            {
                return;
            }

            // A material asset referencing URP/Lit makes the build ship that shader; Shader.Find alone gets stripped.
            Directory.CreateDirectory(Path.GetDirectoryName(BaseMaterialPath));
            var material = new Material(Shader.Find("Universal Render Pipeline/Lit"));
            material.SetFloat("_Smoothness", 0.1f);
            AssetDatabase.CreateAsset(material, BaseMaterialPath);
            AssetDatabase.SaveAssets();
            Debug.Log($"[CoC] Created {BaseMaterialPath}");
        }

        /// <summary>The one material every Blender-pipeline model shares (spec: one material, GPU instancing).</summary>
        private static void EnsurePaletteMaterial()
        {
            var texture = AssetDatabase.LoadAssetAtPath<Texture2D>(PaletteTexturePath);
            if (texture == null || AssetDatabase.LoadAssetAtPath<Material>(PaletteMaterialPath) != null)
            {
                return;
            }

            Directory.CreateDirectory(Path.GetDirectoryName(PaletteMaterialPath));
```

```csharp
            {
                return null;
            }

            var instance = Object.Instantiate(model, parent, false);
            instance.name = name;
            var material = PaletteMaterial;
            if (material != null)
            {
                foreach (var renderer in instance.GetComponentsInChildren<Renderer>())
                {
                    renderer.sharedMaterial = material;
                }
            }

            return instance;
        }

        /// <summary>Depth-first search for a named part (Blender object name), e.g. "Umbrella".</summary>
        public static Transform FindPart(Transform root, string name)
        {
            if (root.name == name)
            {
                return root;
            }

            for (var i = 0; i < root.childCount; i++)
            {
                var found = FindPart(root.GetChild(i), name);
                if (found != null)
                {
                    return found;
                }
            }

            return null;
        }
    }
```

```csharp
using UnityEngine;

namespace CultOfComfort.Client
{
    /// <summary>Animation curves for rigid-part characters. Pure functions of time/progress, so they are unit-tested.</summary>
    public static class PartPose
    {
        /// <summary>Degrees he tips backwards when he faints (not quite 90: he lands on his belt bag).</summary>
        public const float SwoonAngle = 88f;

        private const float FallPortion = 0.7f;
        private const float BounceDegrees = 7f;

        /// <param name="progress">0 = standing, 1 = flat in the mud.</param>
        public static float SwoonTilt(float progress)
        {
            var p = Mathf.Clamp01(progress);
            if (p < FallPortion)
            {
                var t = p / FallPortion;
                return SwoonAngle * t * t; // accelerates like a falling plank
            }

            var settle = (p - FallPortion) / (1f - FallPortion);
            return SwoonAngle - Mathf.Sin(settle * Mathf.PI) * BounceDegrees;
        }

        public static float WalkBob(float phase) => Mathf.Abs(Mathf.Sin(phase)) * 0.05f;

        public static float ArmSwing(float phase, bool moving) => moving ? Mathf.Sin(phase) * 35f : 0f;

        /// <param name="remaining">1 when the attack starts, counting down to 0.</param>
        /// <returns>Forward swing in degrees: a short wind-up back, then a big strike, then rest.</returns>
        public static float AttackSwing(float remaining)
        {
            var t = 1f - Mathf.Clamp01(remaining);
            if (t < 0.25f)
            {
                return -30f * Mathf.Sin(t / 0.25f * Mathf.PI);
            }

            return 110f * Mathf.Sin((t - 0.25f) / 0.75f * Mathf.PI);
        }

        public static float HitSquash(float remaining) => 1f - 0.12f * Mathf.Sin(Mathf.Clamp01(remaining) * Mathf.PI);

        /// <summary>Brush-off shake after getting up (degrees of body yaw); <paramref name="remaining"/> goes 1 → 0.</summary>
        public static float ReviveShake(float remaining)
        {
            var r = Mathf.Clamp01(remaining);
            return Mathf.Sin(r * Mathf.PI * 6f) * 9f * r;
        }
    }
}
```

`client/CultOfComfort.Unity/Assets/Scripts/Art/PartAnimator.cs`:

```csharp
using UnityEngine;

namespace CultOfComfort.Client
{
    /// <summary>
    /// Code-driven animation for Blender-pipeline characters made of named rigid parts (Body, Head, ArmL/R, LegL/R).
    /// Views set state (moving, swooning) and fire one-shots (attack, hit); this applies <see cref="PartPose"/> each frame.
    /// Positive X rotation in Unity tips forward, so "backwards" swoon and "forward" swings use the signs below.
    /// </summary>
    public sealed class PartAnimator : MonoBehaviour
    {
        private Transform _body, _head, _armL, _armR, _legL, _legR;
        private Quaternion _bodyRest, _headRest, _armLRest, _armRRest, _legLRest, _legRRest;
        private Vector3 _bodyPosition, _bodyScale;
        private float _phase, _attack, _hit, _swoon, _revive;
        private bool _wasSwooning;

        public bool IsMoving { get; set; }
        public bool IsSwooning { get; set; }

        public void Bind()
        {
            _body = Find("Body", out _bodyRest);
            _head = Find("Head", out _headRest);
            _armL = Find("ArmL", out _armLRest);
            _armR = Find("ArmR", out _armRRest);
            _legL = Find("LegL", out _legLRest);
            _legR = Find("LegR", out _legRRest);
            _bodyPosition = _body != null ? _body.localPosition : Vector3.zero;
            _bodyScale = _body != null ? _body.localScale : Vector3.one;
        }

        public void Attack() => _attack = 1f;

        public void Hit() => _hit = 1f;

        private void Update()
        {
            if (_body == null)
            {
                return;
            }

            var dt = Time.deltaTime;
            _phase = IsMoving ? _phase + dt * 12f : Mathf.MoveTowards(_phase, Mathf.Round(_phase / Mathf.PI) * Mathf.PI, dt * 6f);
            _attack = Mathf.MoveTowards(_attack, 0f, dt * 3.5f);
            _hit = Mathf.MoveTowards(_hit, 0f, dt * 5f);
            _swoon = Mathf.MoveTowards(_swoon, IsSwooning ? 1f : 0f, dt * (IsSwooning ? 1.6f : 2.5f));
            if (_wasSwooning && !IsSwooning)
            {
                _revive = 1f; // he gets up and brushes himself off
            }

            _wasSwooning = IsSwooning;
            _revive = _swoon > 0f ? _revive : Mathf.MoveTowards(_revive, 0f, dt * 1.5f);

            var swing = PartPose.ArmSwing(_phase, IsMoving);
            _body.localRotation = _bodyRest * Quaternion.Euler(-PartPose.SwoonTilt(_swoon), PartPose.ReviveShake(_revive), 0f);
            _body.localPosition = _bodyPosition + Vector3.up * PartPose.WalkBob(_phase);
            _body.localScale = Vector3.Scale(_bodyScale, new Vector3(1f, PartPose.HitSquash(_hit), 1f));
            Rotate(_armL, _armLRest, swing);
            Rotate(_armR, _armRRest, -swing + PartPose.AttackSwing(_attack));
            Rotate(_legL, _legLRest, -swing * 0.6f);
            Rotate(_legR, _legRRest, swing * 0.6f);
            if (_head != null)
            {
                var glance = IsMoving || IsSwooning ? 0f : Mathf.Sin(Time.time * 0.7f) * 10f; // idly unimpressed
                _head.localRotation = _headRest * Quaternion.Euler(0f, glance, 0f);
            }
        }

        private Transform Find(string part, out Quaternion rest)
        {
            var found = ArtLibrary.FindPart(transform, part);
            rest = found != null ? found.localRotation : Quaternion.identity;
            return found;
        }

        private static void Rotate(Transform part, Quaternion rest, float forwardDegrees)
        {
            if (part != null)
            {
                part.localRotation = rest * Quaternion.Euler(forwardDegrees, 0f, 0f);
            }
        }
    }
}
```

```csharp
using UnityEngine;

namespace CultOfComfort.Client
{
    /// <summary>Development builds only: logs average and worst frame rate every 5 s (read with adb logcat).</summary>
    public sealed class FrameRateLogger : MonoBehaviour
    {
        private const float Window = 5f;
        private float _elapsed;
        private int _frames;
        private float _worst = float.MaxValue;

        private void Update()
        {
            var dt = Time.unscaledDeltaTime;
            _elapsed += dt;
            _frames++;
            _worst = Mathf.Min(_worst, 1f / Mathf.Max(dt, 0.0001f));
            if (_elapsed < Window)
            {
                return;
            }

            Debug.Log($"[CoC] fps {_frames / _elapsed:0.0} (min {_worst:0}) over {Window:0}s");
            _elapsed = 0f;
            _frames = 0;
            _worst = float.MaxValue;
        }
    }
}
```
